# POKEWAY SURF — © dev Kikyo

A small offline-ready endless runner starter project. Pikachu runs through three lanes while Arceus chases from behind. Collect PokéCoins and avoid obstacles.

## Run locally
Open `index.html` in a modern browser. For full offline-install support, serve the folder over localhost or GitHub Pages once loaded online the first time.

## Publish with GitHub Pages
1. Create a new GitHub repository named `pokeway-surf`.
2. Upload **all files and folders inside this ZIP** to the repository root (not the ZIP file itself).
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Choose branch `main` and folder `/ (root)`, then Save.
6. Open the Pages URL GitHub provides. Load it once while online; the service worker then caches the game files for offline play.

## Controls
- Swipe left/right or use ← / → to change lanes.
- Swipe up / ↑ / Space to jump.
- Swipe down / ↓ to slide.
- Collect coins; avoid trains and barriers.
